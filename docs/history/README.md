# Historical documents

These are dated logs, audits, release reports and pilot records. Each says what was true **when it was written**. None is current status, and a claim in one of them is not current unless a current document ([index](../README.md)) repeats it.

They moved here from `docs/` in the 2.0.1 repair. Older source comments, benchmark fixture notes and saved records that cite `docs/<NAME>.md` mean `docs/history/<NAME>.md`; they were left as written because rewording them would change saved evidence and the benchmark instrument fingerprint. Records in `docs/night-evidence/` likewise keep their original paths.

[`README-2.0.md`](README-2.0.md) is the previous project README, kept as a dated reference.
