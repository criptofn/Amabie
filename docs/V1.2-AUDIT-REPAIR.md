## Authority transition still required

The native broker still explicitly implements a measurement harness. The product
service's verifier is `runner-not-installed`, enrollment resolution is a stub,
and the candidate lifecycle requires the base and candidate to share a Git
common directory. Simply moving `git merge` into the native process does not
protect shared objects/configuration/refs or safely execute the sealed plan.
A protected production enrollment, immutable candidate intake, confined verifier
and broker-owned Git application path must be implemented together. This is an
unimplemented lifecycle, not a missing boolean, and this pass does not pretend
that denying all provider promotions completes it.
